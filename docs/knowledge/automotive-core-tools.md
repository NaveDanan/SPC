# Automotive Core Tools SPC Playbook

Context
- Automotive SPC often appears with APQP, PPAP, control plans, MSA, FMEA, and reaction plans.
- The chart is part of a control strategy, not a standalone report.

Guidance
- Link chart recommendations to product/process characteristics and the control plan.
- Mention MSA when measurement credibility affects interpretation.
- Require a reaction plan for out-of-control signals.
- Separate process stability from capability submissions.
- Use Cp/Cpk or Pp/Ppk only with valid specification limits and stability context.

Agent tone
- Use practical supplier-quality language.
- Avoid implying compliance with a standard unless the user provides the requirement.
