# Capability And Performance

Core rule
- Capability indices compare process behavior against specification limits, not control limits.
- Stability should be assessed before capability is treated as decision-ready.

Indices
- Cp and Cpk use within-process sigma.
- Pp and Ppk use overall sigma.
- Cpl and Cpu are one-sided capability indices.
- Cpm includes a target penalty when both specs and a target are available.

Readiness
- Ready: continuous data, valid specs, stable control-chart behavior, enough observations, no strong skew or autocorrelation.
- Preliminary: valid specs but instability, small sample size, skew, or autocorrelation exists.
- Not applicable: missing specs, invalid sigma, reversed specs, or attribute data.

Practitioner guidance
- Report the readiness status beside the number.
- Investigate special-cause signals before promising long-term capability.
- Use stratification when product, tool, recipe, or operator mixing is suspected.
