# Measurement System And Data Credibility

Measurement checks
- SPC assumes the measurement system can distinguish real process variation from noise.
- Many repeated values can indicate coarse resolution, rounding, or gage limitations.
- Sudden changes in measurement method can look like special cause.

MSA guidance
- For production decisions, confirm gage repeatability and reproducibility where practical.
- Keep units, calibration state, and inspection method consistent across the baseline.
- Treat high tie rates and suspiciously low variation as diagnostic warnings.

Agent behavior
- Mention measurement-system risk when tie rate is high.
- Ask about gage resolution or inspection changes before interpreting unusual stability.
- Do not recommend capability action from weak measurement data without caveats.
