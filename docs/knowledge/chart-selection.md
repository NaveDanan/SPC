# SPC Chart Selection Playbook

Purpose
- Choose a chart from data structure before interpreting signals.
- Confirm process order, rational subgrouping, and measurement credibility before capability claims.

Selection rules
- Continuous one-at-a-time measurements: use I-MR.
- Continuous rational subgroups: use X-bar R for small subgroups, X-bar S for larger subgroups.
- Proportion nonconforming: use P chart; use NP only when subgroup size is constant.
- Defect counts on a constant opportunity base: use C chart.
- Defect counts with varying opportunities or inspected units: use U chart.
- Small sustained shifts in ordered continuous data: consider EWMA after baseline limits are credible.
- Histogram and scatter plots are exploratory; they do not replace process-ordered control charts.

Before applying a chart
- Verify time/order sequence is meaningful.
- Verify Y columns represent one process stream, product, tool, or family unless the user intentionally stratifies.
- Ask for denominator/opportunity data when recommending P or U charts from counts.
- Ask for subgroup meaning when recommending X-bar charts.
- Treat control limits and specification limits as different concepts.
